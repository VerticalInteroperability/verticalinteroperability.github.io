# Images

The Vertical Interoperability mark: three lifecycle layers, with one arrow that keeps its color through all of them.

| File | Use |
|---|---|
| `logo-mark.svg`, `favicon.svg` | Adaptive: follows the viewer's light or dark setting. Used by the site. |
| `logo-mark-light.svg`, `logo-mark-dark.svg` | Fixed versions for light and dark backgrounds. |
| `logo-lockup-light.svg`, `logo-lockup-dark.svg` | Mark plus "Vertical Interoperability / VECTOR." |
| `png/logo-mark-{light,dark}-{1024,512,256,128,64,32}.png` | The mark as PNG, transparent background. |
| `png/logo-lockup-{light,dark}-{1120x220,2240x440}.png` | The lockup as PNG, transparent background (2240 for print and retina). |
| `png/apple-touch-icon.png` | 180×180 home-screen icon, white background. |
| `png/favicon-32.png` | 32×32 PNG favicon for browsers without SVG favicons. |
| `png/og-image.png` | 1200×630 link-preview image. |

Colors. Light: arrow #1d6f8f, bars #c9d1d9 / #a9b4bf / #8794a1. Dark: arrow #5fb3d4, bars #3a4756 / #56657a / #75859a.
